# AI Text Processing Lab

A simple AI-powered text processing application that demonstrates three common AI text processing tasks: summarization, classification, and information extraction.

## Features

- Text summarization
- Text classification
- Information extraction
- Uses an OpenAI model for text processing
- Reads text from a sample file

## Technologies Used

- Python
- OpenAI API
- Python-dotenv
