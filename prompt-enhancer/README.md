# Prompt Enhancer API

A simple FastAPI application that analyzes user prompts, identifies missing information, and generates an improved prompt using OpenAI.

## Features

- Analyze user prompts
- Identify missing information
- Generate an enhanced prompt
- REST API using FastAPI
- Interactive Swagger documentation

## Technologies Used

- Python
- FastAPI
- OpenAI API
- Uvicorn
- Python-dotenv
